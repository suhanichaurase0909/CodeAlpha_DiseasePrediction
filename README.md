# Disease Prediction Using Machine Learning

## Project Overview
This project is developed as part of the CodeAlpha Machine Learning Internship. It uses machine learning algorithms to classify breast cancer records as Malignant or Benign.

## Objective
To build a machine learning classification system using medical data for educational disease prediction.

## Dataset
- Breast Cancer Wisconsin Dataset
- 569 records
- 30 input features
- Two classes: Malignant and Benign

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Algorithms
1. Logistic Regression
2. Random Forest
3. Support Vector Machine (SVM)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC
- Confusion Matrix

## Project Features
- Data preprocessing
- Exploratory data analysis
- Model training and comparison
- Performance visualization
- Sample prediction
- Model saving

## Internship
CodeAlpha – Machine Learning Internship

## Conclusion
This project demonstrates the application of machine learning algorithms for educational medical data classification.

**Disclaimer:** This project is for educational purposes only and is not intended for real medical diagnosis.
